# Product Guide: Termux Launcher

## Overview
Termux Launcher is a specialized Android launcher and terminal emulator fork of Termux. It bridges the gap between a standard Android home screen and a powerful Linux-like environment, leveraging privileged integrations (like Shizuku) to provide advanced system control and a high-performance User Experience (UX).

## Target Users
- **Android Power Users:** Individuals who demand more control over their devices, requiring deep system access and automation.
- **Developers & Sysadmins:** Professionals needing a reliable terminal environment and development tools on the go.
- **Security Enthusiasts:** Users who utilize Termux for network auditing, scripting, and security research.

## Core Goals
- **Unified UX:** Seamlessly integrate the Android launcher experience with the Termux terminal.
- **Privileged Access:** Utilize Shizuku and local APIs to provide features typically requiring root, such as system resource monitoring, notification management, and volume/brightness control.
- **Performance & Customization:** Deliver a fast, responsive interface that is highly configurable for advanced workflows.

## Key Features
- **Integrated Terminal:** A high-performance terminal emulator based on the Termux core.
- **Launcher Shell:** A home screen that can execute shell commands and display TUI (Terminal User Interface) widgets.
- **Privileged API (Tooie):** System-level endpoints for managing apps, resources, media, and settings via Shizuku.
- **App Search & Management:** Fast, keyboard-centric application launching and management.
- **System Monitoring:** Real-time dashboards for CPU, memory, storage, and network usage.
